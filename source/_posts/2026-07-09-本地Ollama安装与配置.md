## 0x03.自定义使用Ollama

### 从GGUF导入

GGUF (GPT-Generated Unified Format) 是一种文件格式，用于保存经过微调的语言模型。这种格式旨在帮助用户方便地在不同的平台和环境之间共享和导入模型。它支持多种量化格式，可以有效减少模型文件的大小。

它的前身是GGML(GPT-Generated Model Language)，是专门为了机器学习而设计的Tensor库，目的是为了有一个单文件的格式，并且易在不同架构的CPU以及GPU上可以推理，但后续由于开发遇到了灵活性不足、相容性及难以维护的问题。

Ollama支持从GGUF文件导入模型。首先是下载`.gguf`文件，下载地址为 https://huggingface.co/RichardErkhov/ 。

如果选用Qwen2-0.5B模型，下载地址为 https://huggingface.co/RichardErkhov/Qwen_-_Qwen2-0.5B-gguf/resolve/main/Qwen2-0.5B.Q3_K_M.gguf?download=true 。

下载后我将其放入到的`～models`目录，然后创建Modelfile文件，执行如下内容：

```
touch Modelfile
echo 'FROM ./Qwen2-0.5B.Q3_K_M.gguf' > Modelfile
```

然后一定在Modelfile文件所在的目录下运行以下终端指令：

```
ollama create mymodel -f Modelfile
```

然后ollama运行mymodel：

```
ollama run mymodel
```

### 从Pytorch或Safetensors导入

Safetensors是一种用于存储深度学习模型权重的文件格式，它旨在解决安全性、效率和易用性方面的问题。目前这部分功能还有待社区成员开发，目前文档资源有限。

### 从HuggingFace直接导入

HuggingFace提供了非常便捷的API来下载和处理这些模型，像上面那样直接下载受限于网络环境，速度非常慢，这一小段我们来使用脚本以及hf来完成。

最直接的下载方式是通过git clone或者链接来下载，但是因为llm每部分都按GB计算，避免出现 `OOM Error(Out of memory)`，可以使用Python写一个简单的`download.py`。

去HuggingFace拿到`ACCESS_TOKEN`使用下面的脚本进行下载：

```
!pip install huggingface_hub
```

```
from huggingface_hub import snapshot_download

model_id = "Qwen/Qwen1.5-0.5B" # hugginFace's model name
snapshot_download(
    repo_id=model_id, 
    local_dir="Qwen-0.5b",
    local_dir_use_symlinks=False,
    revision="main",
    use_auth_token="<YOUR_ACCESS_TOKEN>")
```

我注册的时候，HuggingFace一直注册不上，通过Hugging Face Command Line Interface (CLI)工具下载模型一样可以下载。

![Clipboard_Screenshot_1783568671](/assets/img/Ollama-assets/Clipboard_Screenshot_1783568671.png)

首先在macOS和Linux平台下载CLI：

```
curl -LsSf https://hf.co/cli/install.sh | bash
```

下载完成后可以使用该工具完成特定模型的下载，这里以下载`Qwen/Qwen1.5-0.5B`为例：

```
hf download Qwen/Qwen1.5-0.5B
```

## 0x04.end

关于自定义Promt即在Modelfile中定义即可。

```
FROM qwen3:0.6b
# sets the temperature to 1 [higher is more creative, lower is more coherent]
PARAMETER temperature 1

# sets a custom system message to specify the behavior of the chat assistant
SYSTEM You are Mario from super mario bros, acting as an assistant.
```

关于模型存储位置，Ollama在Mac系统中的默认下载模型位置为 `~/.ollama/models/blobs` （如下图所示）。同Windows与Linux系统，Mac系统也是通过设置`OLLAMA_MODELS`变量来控制模型下载路径，可以通过两种方式设置下载路径。

- 使用`launchctl setenv`设置`OLLAMA_MODELS` ，该命令的效果是临时的，即在电脑重启或注销账号后丢失，在设置完环境变量后可以通过使用`launchctl getenv OLLAMA_MODELS`查看当前环境变量。
- 永久更改下载路径，通过 `nano ~/.zshrc` 命令编辑 `~/.zshrc` 文件，在文件中添加 `export OLLAMA_MODELS="/Users/lta/Desktop/models"` 。在保存并退出编辑器后运行 `source ~/.zshrc` 来使其生效即可。

更改完后重启Ollama即可。

关于Ollama在GPU中运行，Ollama默认情况下使用CPU进行推理。为了获得更快的推理速度，可以配置Ollama使用的GPU。前提条件如下：

- 电脑有NVIDIA显卡；
- 已安装NVIDIA显卡驱动程序，可以使用命令 `nvidia-smi` 来检查驱动程序是否安装；
- 已安装CUDA工具包，可以使用命令 `nvcc --version` 来检查CUDA是否安装；

具体如何开启参考 https://datawhalechina.github.io/handy-ollama/#/C3/3.%20%E8%87%AA%E5%AE%9A%E4%B9%89%E5%9C%A8%20GPU%20%E4%B8%AD%E8%BF%90%E8%A1%8C 。
